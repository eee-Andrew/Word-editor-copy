# WordCraft for Windows (portable)

A portable 64-bit Windows build of [WordCraft](https://github.com/storytold/wordcraft), an open-source, Rust-native word processor, with Greek spelling and hyphenation built in.

## Download and run

1. Go to [Releases](https://github.com/eee-Andrew/Word-editor-copy/releases/latest) and download `wordcraft-0.6.1-windows-x64-portable.zip`.
2. Right-click the ZIP and choose **Extract All...**
3. Open the extracted folder and double-click `wordcraft.exe`.

Nothing else to install: no Rust, Visual Studio or other tools. If Windows SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway** (the build is not code-signed).

`wordcraft-cli.exe` is the optional command-line tool. Requires 64-bit Intel/AMD Windows.
